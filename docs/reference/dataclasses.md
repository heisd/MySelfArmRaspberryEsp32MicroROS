# 本文主要是介绍dataclasses库的用法
dataclasses库主要用来减少我们定义一个类的代码量
在python3.7版本之后是python内置的一个功能包
dataclass相当于内置了类的三种方法

1.__init__

2.__eq__ 提供了对象属性的一键打印

3.__repr__ 提供了两个对象的比较，如果相同返回true，不同返回false
